# Research library

Use this library to select evaluated evidence for a recommendation without treating industry research as evidence of an owner's current workflow.

## Selection

| Need | Read | Do not infer |
|---|---|---|
| Determine whether verification is the likely constraint | `claims/verification-capacity.md` | That this owner's bottleneck is verification |
| Choose or test the repeating delivery unit | `patterns/reviewable-value-slice.md` | That every workflow needs a staged pipeline |
| Place human review boundaries | `patterns/sequential-human-checks.md` | The owner's retained decision or authority |
| Separate mechanical evidence from interpretation | `controls/deterministic-before-model-judgment.md` | That a required tool or protected gate exists |
| Define pilot outcome measurement | `measures/production-qualified-value-slice.md` | A baseline, saving, or observed improvement |
| Resolve source metadata | `sources/source-register.md` | That standards prove local effectiveness |
| Trace research into plugin artifacts | `research-map.md` | That an adaptation has been implemented |

## Reading rule

1. Read this router.
2. Read one selected card.
3. Read only the source-register rows named by that card when provenance needs inspection.
4. Present applicability conditions and owner evidence still required.
5. Stop for owner confirmation before the recommendation becomes part of a workflow package or pilot.

## Evidence namespaces

- `E...` — owner interview evidence.
- `D...` — inspected owner documents.
- `R-...` — evaluated research cards in this library.
- `S-...` — sources in `sources/source-register.md`.
- `A...` — explicit design assumptions.

## Boundary

This library supports proposed practices, reasons, measures, tests, and controls. It never supplies current steps, owner quotations, retained-decision rules, baseline values, access claims, or approval status.
