# Claim inventory

| Domain | Claim | Strongest source class | Contrary or qualifying evidence | Status entering evaluation |
|---|---|---|---|---|
| Economics | AI lowers implementation time. | Controlled field experiments | METR measured a slowdown for experienced maintainers. | Contested by context. |
| Flow | Faster code generation moves the system constraint. | NBER field study; DORA | The exposed constraint varies by organization. | Supported with qualification. |
| Intent | Explicit acceptance criteria improve agent work. | Practitioner and emerging empirical evidence | Heavy specifications can add bureaucracy and become stale. | Plausible; scope-dependent. |
| Verification | Generated output requires stronger executable feedback. | DORA, security studies, practitioner convergence | Some studies find no maintainability degradation in bounded settings. | Strongly supported. |
| Review | AI review can replace line-by-line human review. | Vendor capability claims | Review-agent quality and adoption evidence is mixed; accountability remains human. | Unsupported as a general claim. |
| Governance | Prompts and skills can enforce policy. | Vendor documentation | They are advisory unless backed by external enforcement. | Contradicted as a hard-control claim. |
| Autonomy | End-to-end autonomous SDLC loops are desirable. | Vendor methodology and opinion | OWASP/NIST and practitioner research favor bounded delegation and least agency. | Untested and risk-dependent. |
| Operations | Production telemetry should create new development intent. | DevOps/SRE practice and practitioner consensus | Automated remediation adds false-action and authority risk. | Supported for feedback; qualified for action. |
| Learning | Repeated corrections should update repository controls. | RLP/ICM methodology | Unfiltered memory causes context and maintenance debt. | Supported with filtering. |
| Measurement | Commits, PRs, or generated code indicate productivity. | Vendor activity studies | SPACE, DevEx, DORA, and NBER distinguish activity from delivery and value. | Contradicted. |
| Unit of flow | A small production-qualified value slice is preferable to a session or PR. | Lean, XP, DORA, sequence-verifiable-unit principles | Reviewability and value need operational definitions. | Working hypothesis. |
